# PR #138 adversarial self-review — 2026-10-22

Scope: review the initial quote-lookup patch `aff22ff` against its stated missing-slot-only boundary. This is an adversarial review by the implementing agent, **not an independent second-agent sign-off**. The independent source audit identified the original defect; it did not review this implementation.

## Verdict

**The first patch was not ready to merge unchanged.** Four failure modes were reproduced and corrected before requesting merge. No financial records, workflows, capture scope, staking, thresholds or ticket-generation entry points were changed.

## Confirmed findings and corrections

### R1 — High: swapped double chance could price the opposite team

The new fallback remapped home/away team totals, but not `dc/1x` versus `dc/x2`. A home-or-draw recommendation could consume the reversed provider's home-or-draw quote, which covers the opponent instead.

Correction: remap `1x` ↔ `x2` only for a reversed equivalent fixture in the new fallback. The existing exact-slot and exact-pair-absent paths are not redesigned.

Regression: `test_alias_swapped_double_chance_prices_the_selected_team` and `test_alias_swapped_double_chance_never_prices_the_opponent` (both pick sides).

### R2 — High: bucket-level squad identity did not bind individual quotes

`names` stores the first spelling seen for a normalized pair. The nine-character key strips squad markers, so a bucket can contain both senior and women's observations. Checking the bucket's first names did not prevent a later women's quote from pricing the senior fixture. Conversely, first-observed women's names could hide the valid senior quote.

Correction: the four existing source loaders retain raw participant names on each **in-memory** fixture quote. The new fallback validates both raw participants and squad classes per quote, in the correct orientation. A newly admitted alias quote without that identity evidence is refused. Existing quote fields retain their positions; captured files and their schemas are not rewritten. The first five quote fields remain unchanged, BetExplorer admission remains at position five, and optional participant names occupy position six. Index reads do not mutate the captured inputs.

Regression: `test_alias_production_loader_binds_squad_identity_to_each_quote` drives real temporary CSVs through `load_prices_index`, in both first-observed orders. It retains the valid senior price and excludes the later women's offer from price and consensus. `test_alias_fallback_refuses_quotes_without_row_identity` covers missing identity evidence.

### R3 — Medium: absent/invalid decision time disabled the decision cutoff

The inherited witnessed-price loop compares capture to decision only when `as_of` parses. The new admission path therefore accepted aliases with no aware decision, and also accepted a decision at/after kickoff.

Correction: **only the new alias path** requires an aware decision strictly before expected kickoff. Its quotes still pass the existing capture and kickoff checks. Existing exact-slot behavior is explicitly left unchanged rather than quietly expanding this patch into a global clock-policy change.

Regression: `test_new_alias_admission_requires_a_pre_kickoff_decision` covers absent, empty, malformed, naive, equal-to-kickoff and post-kickoff decisions. Boundary/offset tests preserve the existing 15-minute quote-kickoff tolerance. `test_redteam_hardening_does_not_change_existing_exact_slot_clock_policy` pins the scope boundary.

### R4 — High: a shared nine-character prefix was insufficient club identity

The existing provider matcher can accept `Manchester City` as `Manchester United`, `Universidad de Chile` as `Universidad Catolica`, or `Lokomotiv Moscow` as `Lokomotiv Plovdiv` solely through the truncated key. An alternative spelling on the other participant made those wrong fixtures reachable through the new fallback.

Correction: add an optional `allow_truncated` argument to the **existing** matcher, defaulting to its current behavior. The new alias path disables only that shortcut; existing full-name equality, prefix and significant-token rules remain. Existing callers retain the default policy. No parallel matcher, alias registry, similarity threshold or source switch was added. Raw quote identity also refuses cases matching both orientations.

Regression: `test_new_alias_admission_cannot_use_shared_nine_character_club_prefix` covers all three distinct-club pairs. Existing affix-spelling positives still pass.
