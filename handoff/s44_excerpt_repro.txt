    2010-02-17  Newcastle 4:1 Coventry       -> Newcastle
    2009-12-09  Coventry 0:2 Newcastle       -> Newcastle
    2008-08-26  Coventry 2:3 Newcastle       -> Newcastle
    2005-01-29  Newcastle 3:1 Coventry       -> Newcastle
    2001-01-13  Newcastle 3:1 Coventry       -> Newcastle
    2000-09-06  Coventry 0:2 Newcastle       -> Newcastle
  Every one of those six is a Newcastle win, so the same six rows would be
  0 wins / 0 draws / 6 wins - the page's summary says 0 / 1 / 5, i.e. it
  summarises ITS own window (the older meetings supply the draw), not the
  newest six. h2h_meetings stores the summary integer (the number in the
  label) and h2h_rows stores the dated list; neither is a claim about the
  other, and the label is not the length of the list.
