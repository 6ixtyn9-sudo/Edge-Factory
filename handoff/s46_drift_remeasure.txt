Fixture: **JS El Biar vs CR Belouizdad** (`lKAT82nf`, Algeria Ligue 1 — the day's
`match_over_35` board pick).
URL: `https://www.betexplorer.com/match-odds/lKAT82nf/1/ou/bestOdds/?lang=en`

Provenance plainly: this sandbox's bash has **no** route to betexplorer.com; both
reads came through the page-fetch tool, which returns the served response's text
(raw HTML bytes are not retrievable, so attribute-level facts stay unverified).
Per-row values are **read-time** values, and this file exists because they moved
between reads.

## What this does and does not establish

* **Does**: the second reference fixture's served rows and counts **drift between
  reads** — the bookmaker set on the 0.50 line grew from one to two inside the
  same day, and the page's own average for the line moved. That is why no
  per-row price in any artifact of this branch is quoted as a fixed fact, and why
  the parser's contract is "keep what the response served, with the row's own
  bookmaker and creation stamp" rather than a re-derivable average.
* **Does not**: re-measure the 1.50 / 2.50 / 3.50 / 4.50 lines. Only the 0.50
  line and the tab strip were read in this sample; the rest stay **unverified in
  this round** and are not claimed here either way. The recorded per-line values
  above remain the record of the round-2 read, not of the current page.
